対象のソースと README · uv の導入手順

calc では数値と演算子を使用します。引用符なしで乗算する場合は * の代わりに mul を使用してください。

olnm hub は NagoyAction の nagoyaction hub に引数と終了コードをそのまま渡します（olnm に forge のコードはありません）。forge の状態（$OLNM_HOME/forge/state.json）があるとき、olnm dial の変更も nagoyaction hub dial に任せます。ダイヤルは offline / local / mirror / github の名前で指定し、保存ファイルには従来どおり数字 0〜3 が入ります。
